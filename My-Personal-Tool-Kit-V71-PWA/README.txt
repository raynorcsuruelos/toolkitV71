My Personal Tool Kit V71 PWA

Upload ALL files and the icons folder to the same HTTPS website directory (e.g. GitHub Pages). Open index.html, then use the browser Install app / Add to Home Screen option. Visit once online before using offline.

Important: External CDN libraries or fonts may need internet on first use. Local browser data is device/browser-specific; use the Full Toolkit + Data backup regularly. The HTML is copied unchanged from V71 Backup Fixed. Opening index.html directly as file:// will not enable PWA installation.
